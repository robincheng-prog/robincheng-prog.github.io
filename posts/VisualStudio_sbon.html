如何在 Visual Studio 2022 / 2026 / VS Code 上產生符合歐盟 CRA 規範的 SBOM

本指南說明如何在 Visual Studio (2022 / 2026) 或 Visual Studio Code 開發環境中，使用 CycloneDX .NET CLI 工具為 C# 專案產生符合**歐盟網路彈性法案（EU Cyber Resilience Act, CRA）**要求之 CycloneDX 1.6 格式軟體物料清單（SBOM）。

跨 IDE 與跨版本相容性說明

備註：

本指南中的指令與操作步驟完全相容於 Visual Studio 2022、Visual Studio 2026 以及 Visual Studio Code。

由於 CycloneDX CLI 本質上是透過 .NET SDK（dotnet CLI）獨立運作，並不依賴特定的 IDE 內部引擎，因此無論使用哪一種開發工具或升級版本，命令與流程皆完全一致。

為什麼選擇 CycloneDX 格式？

  • 歐盟 CRA 最佳相容性：原生支援 VEX (Vulnerability Exploitability eXchange)，便於追蹤與標註漏洞可利用性。
  • 符合德國 BSI 指引：德國資訊安全局發布的 TR-03183 指南（針對 CRA SBOM 之具體實施指引）已將 CycloneDX 1.6 列為主要採納標準。
  • 開發者友善：支援輕量化 JSON / XML 格式，適合自動化整合與技術文件歸檔。

完整操作步驟

步驟一：開啟內建終端機 (Terminal)

根據您使用的開發工具開啟終端機：

  • Visual Studio (2022 / 2026)：點選頂端選單 檢視 (View) > 終端機 (Terminal) (或按快捷鍵 Ctrl + )。
  • Visual Studio Code：點選頂端選單 Terminal > New Terminal (或按快捷鍵 Ctrl + )。

產出結果驗證與歸檔

  1. 檢查檔案：開啟產出的 .json 檔案，確認頂層欄位包含 "specVersion": "1.6"，且 "components" 完整列出專案所引用的 NuGet 套件與版號。
  2. CRA 備查要求：將產出的 SBOM 檔案納入版本控制，並隨每次產品發布（Release）歸檔於技術文件中，以備歐盟 CRA 合規審查。
