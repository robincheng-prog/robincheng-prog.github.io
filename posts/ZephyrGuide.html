Zephyr入門指南

1. 設定Zephyr

1.1 準備 Zephyr 環境

本說明將引導您完成在 Windows 作業系統上使用 Visual Studio Code (VS Code) 和 MCUXpresso 擴充功能啟動並執行 Zephyr 開發環境的基本步驟。
本次演示旨在讓設定變得快速簡便，以便您現在就可以開始開發應用程序，而無需陷入細節。

  1. 下載並安裝 VS Code

  1. 安裝適用於 VS Code 的 MCUXpresso 擴展，並添加 NXP 的官方擴展以啟用嵌入式開發功能。

  1. 運行 MCUXpresso 安裝程式。使用安裝程式設定軟體開發工具包 (SDK)、工具鏈和環境。

  1. 安裝 Zephyr 倉庫。克隆並配置 Zephyr 倉庫以完成設定(下載需要大量的間時）。

  1. 安裝 MCUXpresso 設定工具。Zephyr的引腳工具支援適用於 25.03 及更高版本。

  1. 安裝 MCUXpresso 安全設定工具

1.2 安裝工具鏈

NXP 為 VSCode 提供了一個名為 MCUXpresso for VS Code 的免費擴充功能。
下載 VS Code 以存取擴充功能庫。

取得 VS Code

請按照以下教學學習如何在主機上安裝 VS Code。

1.3 使用 Zephyr Developer 快速啟動您的設計

MCUXpresso 安裝程式包含一個名為「Zephyr Developer」的選項，可讓您下載除 Zephyr SDK 之外的所有必要元件、工具和相依性。 Zephyr SDK 包含適用於 Zephyr 及其支援的每種架構的工具鏈，其中包括編譯器、彙編器、連結器以及建立 Zephyr 應用程式所需的其他程式。

在 MCUXpresso for VSCode 的「快速啟動面板」中找到 MCUXpresso 安裝程式。

1.4 MCUXpresso 配置工具

MCUXpresso 配置工具是一套整合的配置工具，可引導使用者建立新的 MCUXpresso SDK 專案。它還包含引腳和時脈工具，用於產生自訂板級支援的初始化 C 程式碼。引腳工具具有圖形使用者介面 (GUI)，可協助使用者選擇應用程式使用的所有所需訊號，並配置引腳復用和引腳設定。從 v25.03 版本開始，設定工具可以為 i.MX RT1xxx 和 MCX 裝置產生 Zephyr 板級 pinctrl 檔案。 Zephyr 使用 pinctrl 來設定係統單晶片 (SOC) 的接腳和接腳重複使用設定。

點擊下面的「取得 MCUXpresso 設定工具」按鈕，即可取得設定工具安裝程式。

取得 MCUXpresso 設定工具

1.5 編程和配置工具

MCUXpresso 安全配置 (SEC) 工具是一款基於圖形使用者介面 (GUI) 的應用程序，旨在簡化在恩智浦 (NXP) 微控制器單元 (MCU) 裝置上產生和配置可引導執行檔的流程。我們建議所有使用者先使用 MCUXpresso SEC 工具進行試運行和大量生產。它支援在生產階段對恩智浦微控制器進行安全編程和設備配置。下載該工具後，您可以在「說明」標籤下找到使用者指南。請依照「處理器特定工作流程」章節中針對您的開發板的說明進行操作。

下載 SEC

1.6 熟悉 VS Code 的 MCUXpresso

MCUXpresso for VS Code 的主要功能特性

剛開始使用 MCUXpresso for VS Code 時，了解一些關鍵功能和工具會很有幫助，它們可以簡化您的開發體驗。本節將為您提供一個概覽，而非深入講解，讓您快速上手。

快速入門面板

快速入門面板是您建立、匯入和管理專案的啟動平台。它提供了常用任務的捷徑。其中最常用的快捷方式是「從儲存庫導入範例」和「開啟 MCUXpresso 安裝程式」。

專案視圖

這裡是您的工作區和專案文件所在的位置。了解 Zephyr 專案的結構將有助於您更有效地瀏覽和管理程式碼。

設備樹

設備樹描述了硬體佈局和配置。編譯 Zephyr 專案並刷新設備樹視圖後，它將以樹狀結構顯示專案硬體層次結構。您也可以查看節點及其關聯值。

完美建造

全新建置用於從頭開始清理和重建專案。在切換配置或解決建置問題時，它尤其有用。

偵錯

MCUXpresso for VSCode 可與多種調試器整合。借助它，您可以學習如何設定斷點、單步執行程式碼以及檢查變量，從而有效地進行故障排除。

終端機和串口監視器

該終端機旨在實現與導入的儲存庫進行命令列互動。串口終端可讓您透過 UART 與開發板進行互動。這對於日誌記錄、調試和即時通訊非常有用。

1.7 硬體準備

本步驟指南將以 FRDM-MCXC242 開發板為例，指導您如何開始使用 Zephyr。當然，您也可以使用其他評估板，並遵循相同的基本流程。

  1. 選擇您的評估委員會

本指南使用 FRDM-MCXC242 開發板，您也可以使用其他支援的開發板，但請務必：

  • 確認您的主機板是否支援 Zephyr
  • 請檢查是否有任何針對特定電路板的設定說明
  1. 更新板載調試器韌體
    大多數評估板都帶有板載調試器。為確保相容性和穩定性：請確認您評估板的調試器韌體已更新至最新版本。

從LinkServer 韌體頁面下載最新韌體。選擇合適的韌體類型：

  • Cortex 微控制器軟體介面標準偵錯存取連接埠 (CMSIS-DAP)
  • Segger J-Link

  1. 如果您的開發板沒有板載偵錯器，請將外部偵錯器連接到目標開發板。

  2. 給電路板供電
    開發過程中需要為開發板供電。常用供電方式包括：

  • USB 連接線（最常見）
  • 圓筒形插孔連接器（適用於某些電路板）
  1. 將電路板插入電源
