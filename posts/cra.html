歐盟《網路韌性法案》

歐盟《網路韌性法案》（Cyber Resilience Act, CRA / EU 2024/2847）是歐盟針對具備數位元素產品（Products with Digital Elements, PDEs）所頒布的首個橫向強制性網路安全法規。

1. 核心規範原則

CRA 將資安責任直接歸屬於製造商、進口商與經銷商，主要原則包括：

  • 設計即安全（Secure-by-Design & Default）： 產品在規劃與開發階段即須納入網路安全考量，且預設設定需具備安全性。
  • 全生命週期管理： 製造商必須在產品生命週期內（至少 5 年或產品預期壽命期間）提供免費的資安更新與漏洞修補。
  • 軟體物料清單（SBOM）： 強制記錄與維護元件清單，確保供應鏈與第三方／開源套件的透明度與風險控制。
  • CE 標誌強制認證： 符合 CRA 要求的產品才可貼上 CE 標誌並於歐盟市場銷售。

2. 適用範圍與排除對象

適用範圍

涵蓋所有直接或間接連接至網路或裝置的硬體與軟體產品，例如：

  • 消費性電子： 智慧家電、網路攝影機、穿戴式裝置、路由器等。
  • 工業與商業設備： 工業控制器（PLC）、感測器、網關（IoT Gateway）及管理軟體。
  • 獨立軟體： 操作系統、韌體、應用軟體及各類聯網工具。

排除對象

已有其他專屬嚴格資安法規監管的產品不適用 CRA：

  • 醫療器材（受 MDR / IVDR 規範）
  • 車用設備（受 UN R155 / R156 等車用標準規範）
  • 民航航空設備與國防軍事產品

3. 產品風險等級與合格評鑑模式

CRA 依據產品的資安風險高低，將產品劃分為不同等級並採取不同的合格評鑑模式（Conformity Assessment）：

  1. 預設 / 一般產品（Default / Non-Critical）：
  • 評鑑方式： 製造商可透過自我宣告（Self-assessment）確認符合 CRA 技術要求並簽署 EU Declaration of Conformity。
  1. 重要產品 Class I（Important Class I）：
  • 評鑑方式： 若有完全套用歐盟「調和標準（Harmonised Standards）」，可採用自我宣告；若無，則需由歐盟認可之第三方合格評鑑機構（Notified Body）進行審查。
  1. 重要產品 Class II（Important Class II）與關鍵產品（Critical）：
  • 評鑑方式： 強制要求第三方驗證或取得指定之歐盟網路安全認證計畫（EUCC）證書。

4. 關鍵時間軸

時間 里程碑與法律義務
2024 年 12 月 10 日 CRA 法案正式生效（進入過渡期）。
2026 年 6 月 11 日 合格評鑑機構（Notified Body）相關要求生效。
2026 年 9 月 11 日 漏洞與資安事件通報義務強制上路（發生主動利用漏洞或重大事件時，須於 24 小時內通報 ENISA 與主管機關）。
2027 年 12 月 11 日 CRA 全面強制實施（不符合資安要求之產品不得在歐盟市場銷售）。

5. 罰則機制

若未遵守 CRA 規範，違規企業將面臨重罰：

  • 技術要求未合規： 最高 1,500 萬歐元 或 全球年營業額 2.5%（以較高者為準）。
  • 通報義務未履行： 最高 1,000 萬歐元 或 全球年營業額 2.0%（以較高者為準）。
  • 監管機關有權要求違規產品下架、召回或禁止在歐盟境內銷售。

6. 企業因應建議與現行參考標準

由於歐盟 CRA 的調和標準（Harmonised Standards）仍在由 CEN/CENELEC 與 ETSI 陸續制定與調和中，現階段企業可基於以下既有國際資安標準建置合規體系：

  • 工業控制與嵌入式設備： ISA/IEC 62443（特別是 62443-4-1 安全開發生命週期與 62443-4-2 元件安全）。
  • 消費性物聯網（IoT）： ETSI EN 303 645。
  • 軟體供應鏈與 SBOM： SPDX 或 CycloneDX 格式標準。
  • 通用資安驗證： ISO/IEC 27001、ISO/IEC 29147（漏洞揭露）及 ISO/IEC 30111（漏洞處理）。

如何判定我的數位產品在歐盟 CRA 下屬於一般類別、Class I 還是 Class II

判定數位產品在歐盟 CRA（Cyber Resilience Act）下的分類，關鍵在於「產品的核心功能」以及「產品若遭受破壞後可能造成的風險與連帶影響層面」。

歐盟 CRA 採用「負面清單法（Exclusion / Designated List）」：先檢查產品是否屬於 Annex III（重要產品 Class I / II） 或 Annex IV（關鍵產品）；若皆不在清單上，則預設歸類為一般類別（Default）。

您可以依照以下三步驟來進行判定：

第一步：是否落在 Annex III Class II（高風險重要產品）？

若產品具備極為關鍵的資安防護、系統底層控制或防篡改功能，通常屬於 Class II。此類產品強制必須由第三方機構（Notified Body）進行審查驗證。

常見 Class II 產品項目包括：

  • 底層虛擬化與容器系統： Hypervisors、Container runtime systems。
  • 資安防護設備： 防火牆（Firewalls）、入侵偵測與預防系統（IDS/IPS）。
  • 高安全性晶片與硬體： 具備防篡改能力的微處理器/微控制器（Tamper-resistant microprocessors / microcontrollers）。

💡 評鑑方式： 不可自我宣告，必須通過第三方認證（Modules B+C 或 Module H）。

第二步：是否落在 Annex III Class I（中風險重要產品）？

若產品具備身分驗證、加密、網路管理或保護關鍵隱私/安全等功能，但未達到 Class II 的底層影響力，則屬於 Class I。

常見 Class I 產品項目包括：

  • 資安與憑證工具： 密碼管理器（Password managers）、PKI 憑證核發軟體、VPN 軟體/設備、防毒/掃毒軟體。
  • 網路與系統管理： 網路管理系統、SIEM 系統、引導管理器（Boot managers）、作業系統（OS）、網路介面卡、路由器、數據機與交換器。
  • 安全相關晶片與組件： 具備資安相關功能的 MCU、MPU、ASIC 與 FPGA。
  • 特殊消費性/物聯網裝置：
  • 智慧家庭安全產品（如智慧門鎖、監控攝影機、嬰兒監視器、警報系統）。
  • 具備社交互動或定位追蹤功能的聯網玩具。
  • 具備健康監測功能或兒童專用的個人穿戴式裝置。

💡 評鑑方式： 若完全符合歐盟調和標準（Harmonised Standards），可採用自我宣告（Self-assessment）；若缺乏適用標準，則需經由第三方驗證。

第三步：是否不在清單內？（歸類為 Default 一般產品）

歐盟約有 80%～90% 的數位產品屬於此類別。只要產品不具備上述專用的高風險資安功能，且未列入 Annex III / IV，即屬於一般類別（Default）。

常見 Default 產品包括：

  • 一般消費性電子（如一般智慧家電、一般藍牙音響、智慧手錶/手環（非兒童用且無特殊健康數據監測））
  • 一般工業用非安全相關之感測器與資料擷取模組
  • 一般應用軟體（如文字處理軟體、圖像編輯軟體、相機 App 等）
  • 一般微控制器/單晶片（未宣稱具備硬體資安防護功能者）

💡 評鑑方式： 製造商直接進行**內部生產控制與自我宣告（Self-assessment）**並貼上 CE 標誌即可。

⚠️ 特別注意事項：組件與整體產品的關係

如果您的產品整合了屬於 Class I 或 Class II 的零件（例如您的智慧工業控制板選用了具備資安功能的 Class I MCU），整體產品並不一定會被直接升級為 Class I 或 Class II。

  • CRA 的分類是看「產品作為一個整體（Product as a whole）」對外呈現的功能與主要用途。
  • 只有當整體產品本身的核心功能就是 Annex III 所列出的項目時，才需要遵照相應的更高階合格評鑑程序。
