Cursor 編輯器從零到一完整指南

Cursor 是基於 VS Code 開發的，如果你本來就使用 VS Code，將可以無痛轉換，並體驗 AI 帶來的全新開發流程。

第一步：下載與安裝

  1. 下載安裝檔: 預估時間：1 分鐘.

    • 前往 Cursor 官方網站，系統會自動偵測您的作業系統（Windows / macOS / Linux），點擊 Download 下載。

  2. 執行安裝: 預估時間：2 分鐘.

    • Windows： 雙擊執行 .exe 檔，依指示完成安裝。
    • macOS： 打開 .dmg 檔，將 Cursor 圖示拖曳到 「應用程式 (Applications)」資料夾中。

  3. 初始設定導覽 (Setup Wizard): 核心步驟！.

    第一次開啟 Cursor 時，會跳出引導畫面，這三個設定至關重要：

    • Keyboard Shortcuts： 選擇你習慣的快捷鍵模式（建議直接選 VS Code）。
    • Language Pack： 可以選擇繁體中文（如果想要介面中文化）。
    • VS Code Extensions Import： 強烈建議勾選！ 這會一鍵把你原本 VS Code 的所有外掛、主題、設定完全複製過來。

  4. 註冊與登入: 啟用 AI 的關鍵.

    • 點擊 Sign Up 註冊一個 Cursor 帳號（直接用 Google 或 GitHub 連動最快）。登入後才能獲得每個月免費的進階 AI 模型使用額度（如 GPT-4o, Claude 3.5 Sonnet）。

第二步：基礎設定與優化（磨亮你的工具）

進入編輯器後，建議先進行以下設定，讓 AI 更貼近你的開發需求：

1. 配置專案上下文 (重要：.cursorrules)

在你的專案根目錄下，建立一個名為 .cursorrules 的純文字檔案。這個檔案是寫給 AI 看的「專案說明書」。

例如你在寫 React，可以在裡面寫：
"本專案使用 React 18 與 Tailwind CSS，請一律使用 TypeScript 撰寫，元件請使用 Arrow Function，並確保符合繁體中文語境。"
這樣一來，AI 每次幫你寫代碼時，都會自動遵守這些規範，不會寫出不合規格的代碼。

2. 開啟進階模型

  1. 按下快捷鍵 Ctrl + , (Mac 為 Cmd + ,) 打開設定。
  2. 在左側找到 Cursor Settings $\rightarrow$ Models。
  3. 確保你常用的模型（如 claude-3.5-sonnet 或 gpt-4o）是有勾選開啟的。在日常編程中，Claude 3.5 Sonnet 的程式碼邏輯與架構能力通常更受工程師推薦。

第三步：最後運行與 AI 核心實戰

設定完成後，我們直接開一個新專案來運行。請點選選單的 File -> Open Folder，打開或新建一個乾淨的資料夾。

接下來，你不需要自己敲鍵盤，試著用以下三個核心功能讓 Cursor 幫你運行：

實戰 1：Ctrl + K (Mac: Cmd + K) —— 行內生成 (Inline Edit)

  1. 在編輯器中建立一個新檔案（例如 index.html 或 app.js）。
  2. 在空白畫面上直接按下 Ctrl + K，會跳出一個輸入框。
  3. 輸入：幫我寫一個倒數計時器的網頁，要有精美的現代感 UI 按鈕，然後按下 Enter。
  4. 你會看到 AI 開始現場串流撰寫代碼，滿意後點擊 Accept（或按 Ctrl + Enter）接收代碼。

實戰 2：Ctrl + L (Mac: Cmd + L) —— 程式碼對話 (Chat)

  1. 選中畫面上剛剛生成的某一段代碼，然後按下 Ctrl + L。
  2. 這段代碼會被自動丟到右側的 AI Sidebar。
  3. 你可以在右側問它：這段程式碼的邏輯是什麼？有沒有潛在的記憶體洩漏風險？ 它會逐行幫你解釋並給予優化建議。

實戰 3：Ctrl + I (Mac: Cmd + I) —— 多檔案協同編輯 (Composer)

這是 Cursor 最強大的終極武器。當你想要擴充功能，但牽涉到多個檔案時：

  1. 按下 Ctrl + I 打開 Composer 視窗。
  2. 點擊輸入框中的 @ 符號，選擇 Files 或 Folders，把相關的檔案（例如 style.css 和 index.html）鎖定進來。
  3. 輸入指令：幫我把倒數計時器加上歷史紀錄功能，CSS 要同步調整樣式。
  4. 運行： 點擊 Submit，AI 會同時修改這兩個檔案。修改完畢後，你可以在畫面上即時預覽 Diff 變更，確認沒問題後點擊 Accept All。

💡 運行小叮嚀

當 AI 幫你寫完代碼後，你可以像平常一樣，在 Cursor 底部的 Terminal（終端機） 執行你的啟動指令（如 npm run dev 或直接用 Live Server 開啟網頁），直接檢視運行結果。如果畫面上出現報錯，直接複製報錯訊息丟給右側的 Chat，或者在終端機點擊 “Debug with AI”，Cursor 就會自動幫你修到好！
