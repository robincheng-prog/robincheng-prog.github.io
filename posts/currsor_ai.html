Cursor 編輯器從零到一 完整指南

AI Cursor（AI 光標 / 智能游標） 是目前 AI 輔助程式碼編輯器（如 Cursor AI、VS Code 搭配 Copilot Edit 等）中最核心的創新功能之一。

它顛覆了傳統「複製貼上」或「單行補全」的模式，讓 AI 能夠直接在你的編輯器中，像一個真正的人類工程師一樣移動游標、跨檔案、跨行地自動修改代碼。

以下為您帶來 AI Cursor 的完整功能、運作原理與核心優勢說明：

1. 什麼是 AI Cursor？

傳統的 AI 程式碼助手（如早期的 GitHub Copilot）主要是「預測下一步」，在您輸入代碼時提供灰色的預測文字。

而 AI Cursor 則是「主動編輯器」。當您透過自然語言輸入需求（例如：「幫我把這個元件重構為 TypeScript，並修正所有型別錯誤」）時，AI 會接管編輯器的游標，自動在多個程式碼區塊或多個檔案之間跳躍，直接進行刪除、修改、新增或重構。

2. 核心功能與應用場景

AI Cursor 通常整合在編輯器的 Inline Edit（行內編輯） 或 Composer（多檔案同步編輯） 模式中，主要功能包括：

核心功能

  • 多行與多檔案同步修改： AI 不僅能修改當前游標所在的位置，還能理解代碼關聯性。例如修改了一個 API 的 Function 簽名，AI Cursor 會自動跳轉到呼叫該 API 的其他檔案，同步更新參數。
  • 意圖預測（Predictive Edditing）： 當您手動修改了某一處代碼（例如將 var 改為 let），AI Cursor 會預測您接下來想修改哪裡，並直接將游標導向下一處，您只需按下 Tab 鍵即可完成整套修改。
  • Diff 模式預覽： AI Cursor 在修改程式碼時，會以 Git Diff 的形式（綠色新增、紅色刪除）呈現，讓開發者在按下 Accept（接受）或 Reject（拒絕）前，能一目了然所有的變更。

常見應用場景

  • 代碼重構： 快速將舊代碼結構調整為新的設計模式。
  • 錯誤修復： 點擊錯誤提示，AI Cursor 會自動定位到出問題的程式碼行並直接修正。
  • 撰寫測試： 選中一段 Function，讓 AI Cursor 直接在對應的測試檔案中生成 Test Case。

3. 運作原理

AI Cursor 的強大建立在對專案上下文（Context）的深度理解上：

  1. Context 收集： 當您啟動 AI Cursor 時，它會自動將當前檔案、選中的代碼、編譯錯誤訊息，甚至整個專案的結構（AST，抽象語法樹）作為 Prompt 的一部分。
  2. 模型推導與定位： 像是 GPT-4o 或 Claude 3.5 Sonnet 這類高智能模型，會計算出需要修改的精確行號與字元位置。
  3. 串流編輯（Streaming Edit）： AI 開始像打字員一樣，將修改後的代碼即時「噴」在編輯器畫面上，並伴隨游標的移動，讓開發者可以即時看到修改過程。

4. 關鍵優勢

  • 極大提升開發效率： 省去了「在對話框複製代碼 $\rightarrow$ 回到編輯器選中 $\rightarrow$ 貼上 $\rightarrow$ 調整縮排」的繁瑣步驟。
  • 保持專注（Flow State）： 開發者不需要離開程式碼畫面去瀏覽器查資料或切換到獨立的 AI 聊天視窗，所有的互動都在游標所在的地方完成。
  • 降低出錯率： 由 AI 處理跨檔案的同步命名更新，能有效減少漏改、錯改導致的編譯失敗。

5. 目前的主流實現

目前將 AI Cursor 概念做得最成熟的產品包括：

  • Cursor 編輯器： 作為目前最火紅的 AI First IDE，其 Ctrl+K (Inline Edit) 和 Ctrl+I (Composer) 將 AI Cursor 的多檔案協同能力發揮得淋漓盡致。
  • GitHub Copilot (VS Code 升級版)： 推出的 Copilot Edits 功能，同樣允許 AI 在多檔案中同時引導游標並修改代碼。

總結來說： AI Cursor 讓 AI 從一個「只能給建議的諮詢顧問」，正式升格為「能直接幫你動手寫代碼的虛擬結對編程（Pair Programmer）夥伴」。

Cursor 編輯器

Cursor 編輯器：Cursor 是基於 VS Code 開發的，如果你本來就使用 VS Code，將可以無痛轉換，並體驗 AI 帶來的全新開發流程。

第一步：下載與安裝

  1. 下載安裝檔: 預估時間：1 分鐘.

    • 前往 Cursor 官方網站，系統會自動偵測您的作業系統（Windows / macOS / Linux），點擊 Download 下載。

  2. 執行安裝: 預估時間：2 分鐘.

    • Windows： 雙擊執行 .exe 檔，依指示完成安裝。
    • macOS： 打開 .dmg 檔，將 Cursor 圖示拖曳到 「應用程式 (Applications)」資料夾中。

  3. 初始設定導覽 (Setup Wizard): 核心步驟！.

    第一次開啟 Cursor 時，會跳出引導畫面，這三個設定至關重要：

    • Keyboard Shortcuts： 選擇你習慣的快捷鍵模式（建議直接選 VS Code）。
    • Language Pack： 可以選擇繁體中文（如果想要介面中文化）。
    • VS Code Extensions Import： 強烈建議勾選！ 這會一鍵把你原本 VS Code 的所有外掛、主題、設定完全複製過來。

  4. 註冊與登入: 啟用 AI 的關鍵.

    • 點擊 Sign Up 註冊一個 Cursor 帳號（直接用 Google 或 GitHub 連動最快）。登入後才能獲得每個月免費的進階 AI 模型使用額度（如 GPT-4o, Claude 3.5 Sonnet）。

第二步：基礎設定與優化（磨亮你的工具）

進入編輯器後，建議先進行以下設定，讓 AI 更貼近你的開發需求：

1. 配置專案上下文 (重要：.cursorrules)

在你的專案根目錄下，建立一個名為 .cursorrules 的純文字檔案。這個檔案是寫給 AI 看的「專案說明書」。

例如你在寫 React，可以在裡面寫：
"本專案使用 React 18 與 Tailwind CSS，請一律使用 TypeScript 撰寫，元件請使用 Arrow Function，並確保符合繁體中文語境。"
這樣一來，AI 每次幫你寫代碼時，都會自動遵守這些規範，不會寫出不合規格的代碼。

2. 開啟進階模型

  1. 按下快捷鍵 Ctrl + , (Mac 為 Cmd + ,) 打開設定。
  2. 在左側找到 Cursor Settings $\rightarrow$ Models。
  3. 確保你常用的模型（如 claude-3.5-sonnet 或 gpt-4o）是有勾選開啟的。在日常編程中，Claude 3.5 Sonnet 的程式碼邏輯與架構能力通常更受工程師推薦。

第三步：最後運行與 AI 核心實戰

設定完成後，我們直接開一個新專案來運行。請點選選單的 File -> Open Folder，打開或新建一個乾淨的資料夾。

接下來，你不需要自己敲鍵盤，試著用以下三個核心功能讓 Cursor 幫你運行：

實戰 1：Ctrl + K (Mac: Cmd + K) —— 行內生成 (Inline Edit)

  1. 在編輯器中建立一個新檔案（例如 index.html 或 app.js）。
  2. 在空白畫面上直接按下 Ctrl + K，會跳出一個輸入框。
  3. 輸入：幫我寫一個倒數計時器的網頁，要有精美的現代感 UI 按鈕，然後按下 Enter。
  4. 你會看到 AI 開始現場串流撰寫代碼，滿意後點擊 Accept（或按 Ctrl + Enter）接收代碼。

實戰 2：Ctrl + L (Mac: Cmd + L) —— 程式碼對話 (Chat)

  1. 選中畫面上剛剛生成的某一段代碼，然後按下 Ctrl + L。
  2. 這段代碼會被自動丟到右側的 AI Sidebar。
  3. 你可以在右側問它：這段程式碼的邏輯是什麼？有沒有潛在的記憶體洩漏風險？ 它會逐行幫你解釋並給予優化建議。

實戰 3：Ctrl + I (Mac: Cmd + I) —— 多檔案協同編輯 (Composer)

這是 Cursor 最強大的終極武器。當你想要擴充功能，但牽涉到多個檔案時：

  1. 按下 Ctrl + I 打開 Composer 視窗。
  2. 點擊輸入框中的 @ 符號，選擇 Files 或 Folders，把相關的檔案（例如 style.css 和 index.html）鎖定進來。
  3. 輸入指令：幫我把倒數計時器加上歷史紀錄功能，CSS 要同步調整樣式。
  4. 運行： 點擊 Submit，AI 會同時修改這兩個檔案。修改完畢後，你可以在畫面上即時預覽 Diff 變更，確認沒問題後點擊 Accept All。

💡 運行小叮嚀

當 AI 幫你寫完代碼後，你可以像平常一樣，在 Cursor 底部的 Terminal（終端機） 執行你的啟動指令（如 npm run dev 或直接用 Live Server 開啟網頁），直接檢視運行結果。如果畫面上出現報錯，直接複製報錯訊息丟給右側的 Chat，或者在終端機點擊 “Debug with AI”，Cursor 就會自動幫你修到好！
