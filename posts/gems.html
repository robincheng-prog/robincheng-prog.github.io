Gemini Gem

「Gemini Gem」（或稱 Gems）是 Google 推出的客製化 AI 助手功能，類似於 GPTs。您可以為它設定特定的角色、背景知識與固定指令，讓它自動化執行重複的任務。

建立專屬 Gemini Gem 的 3 個步驟

  1. 前往建立頁面：在裝置上開啟 Gemini ，點擊左側選單的「探索 Gem」（Explore Gems）。

  2. 設定指令與名稱：點擊「新增 Gem」。接著為您的 Gem 命名，並在指令（Instructions）欄位中寫下您期望它扮演的角色與執行步驟。

  3. 上傳知識庫與儲存：您可以額外上傳文件（如 SOP 或風格指南）作為它的參考知識。預覽測試無誤後，點擊「儲存」即可完成設定。

實用 Gem 指令腳本（Prompt 範本）

您可以將以下指令填入 Instructions 欄位，快速打造實用工具：

1. 專業文案潤飾師

2. 會議記錄大師

這裡為您精選 4 個最常見、最能提升生產力的 Gem 客製化指令（Prompt）範本。您可以直接複製，並根據需求微調：

1. 程式碼除錯與優化專家 (Coding Expert)

適用於工程師。這個 Gem 不只能幫您改錯，還會說明原因並提供更好的寫法。

2. 外語商務書信導師 (Email Polisher)

協助跨國溝通。它不會死板地翻譯，而是會根據不同商業情境調整語氣。

3. 社群媒體行銷小編 (Social Media Writer)

幫您快速產出能在 Facebook、Instagram 或 Threads 上吸引目光的貼文。

4. 複雜概念白話文翻譯機 (ELIF Explainer)

適合用來讀複雜的技術文件、學術論文或專有名詞。

為身為軟體工程師的您量身打造 Python、C#、C 語言以及 Shell Script 這 4 套專屬的 Gem 指令腳本。您可以直接複製下方框內的文字，貼進對應 Gem 的「指令（Instructions）」欄位中：

1. Python 萬能開發與重構專家

針對 Python 的動態特性，專注於 PEP 8 規範、記憶體效率、非同步（Asyncio）與型別安全。

2. C# 企業級系統與 .NET 效能顧問

專注於 .NET 現代架構、物件導向原則（SOLID）、記憶體管理（LINQ 優化、ValueTask）與非同步處理。

3. C 語言記憶體與底層系統專家

專注於 C 語言核心：指標安全、記憶體洩漏（Memory Leak）、緩衝區溢位以及編譯器最佳化。

4. Shell Script 自動化與運維專家

專注於腳本的健全度（Robustness）、跨平台相容性（Bash/Sh）、錯誤控制與邊界條件處理。
