Ubuntu 24.04 設定為 HMI

將 Ubuntu 24.04 設定為 HMI（人機介面）系統，主要需要關閉省電、設定自動登入、固定網路 IP、隱藏游標或解鎖觸控與全螢幕自動執行等關鍵設定。

1. 系統電源與螢幕保護設定

工廠或設備的 HMI 需要常亮，不能進入休眠或關閉螢幕。

  • 開啟設定 (Settings) > 電源 (Power)。
  • 將螢幕變暗 (Screen Blank) 設定為從不 (Never)。
  • 關閉自動掛起 (Automatic Suspend) 功能。

2. 設定開機自動登入 (Auto Login)

設備開機後應直接進入 HMI 畫面，不需要手動輸入密碼。

  • 前往設定 (Settings) > 使用者 (Users)。
  • 點擊右上角解鎖（需要輸入密碼）。
  • 開啟自動登入 (Automatic Login) 開關。

3. 固定網路 IP (Static IP)

HMI 通常需透過網卡與 PLC、SCADA 或伺服器穩定通訊。

  • Ubuntu 24.04 使用 Netplan 管理網路。

4. 觸控螢幕與游標校正

若您的 HMI 螢幕為觸控式，需確認觸控座標對應正確。

  • 安裝與使用 xinput 或透過 Wayland/X11 相關工具進行多螢幕觸控對應。
  • 若現場操作不需要滑鼠游標，可安裝 unclutter 套件來自動隱藏無動作時的游標：

5. HMI 應用程式開機自動啟動

  • 將您的 HMI 執行檔（如 Node-RED、Qt 程式、Python 腳本或網頁瀏覽器全螢幕模式）加入開機自動執行。
  • 在 ~/.config/autostart/ 資料夾中建立一個 .desktop 啟動捷徑檔案，指定開機後自動載入 HMI 軟體。

4. 關閉螢幕側邊欄與上邊欄（選用）

Ubuntu 預設的 GNOME 桌面在滑鼠移到邊緣時可能會滑出 Dock 欄。若希望徹底鎖定畫面：

  • 前往設定 (Settings) > 外觀 (Appearance)。
  • 將 Dock 設定為自動隱藏 (Auto-hide the Dock)。
